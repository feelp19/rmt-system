# Nuxt 4 SSR + PrimeVue + Laravel Octane/FrankenPHP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a decoupled Nuxt 4 (SSR) frontend with PrimeVue (Aura) to the existing Laravel 13 project, with Laravel reduced to an API backend running under Octane/FrankenPHP, all served on one origin behind Caddy.

**Architecture:** Monorepo. Laravel = API at `/api/*` under Octane+FrankenPHP worker mode. Nuxt 4 SSR app in `/frontend` served at the root. Caddy (FrankenPHP's embedded Caddy) routes `/api/*` to the Laravel worker in-process and everything else to the Nuxt SSR node service. Browser calls relative `/api` (same-origin → no CORS); SSR calls the internal Laravel URL.

**Tech Stack:** Laravel 13, laravel/octane@2.x, FrankenPHP (dunglas/frankenphp:php8.5), Caddy, Sanctum; Nuxt 4, PrimeVue 4.5.5 + @primevue/nuxt-module 4.5.5 + @primeuix/themes 2.0.3 + primeicons 7.0.0; Node 22; MySQL 8.4; Redis.

**Reference spec:** `docs/superpowers/specs/2026-06-03-nuxt-laravel-octane-primevue-design.md`

**Testing note:** Laravel API logic is tested with PHPUnit (TDD). Infra (Octane install, Docker, Caddy, Nuxt scaffold) is not unit-testable; those tasks use explicit **verification commands** with expected output instead of unit tests. This is called out per task.

Create `frontend/app/composables/useAPI.ts`:

```ts
export function useAPI<T>(path: string, opts: Parameters<typeof useFetch>[1] = {}) {
  const config = useRuntimeConfig()
  const base = import.meta.server ? config.apiBase : config.public.apiBase
  return useFetch<T>(`${base}${path}`, opts)
  // SSR    -> http://localhost:8000/api/health  (config.apiBase + /health)
  // client -> /api/health                       (config.public.apiBase + /health)
}
```

## Task 9: Caddyfile (single-origin routing)

**Files:** Create `Caddyfile`.

Infra task — verification via the end-to-end task (Task 12).

- [ ] **Step 1: Create `Caddyfile`**

```caddyfile
{
	# Octane injects the FrankenPHP worker directive in worker mode.
}

:80 {
	root * /app/public
	encode zstd br gzip

	# API: keep the /api prefix (handle, NOT handle_path) and hand to the PHP worker
	handle /api/* {
		php_server {
			try_files {path} index.php
		}
	}

	# Sanctum CSRF + Laravel-owned paths (optional but useful for SPA cookie auth later)
	handle /sanctum/* {
		php_server
	}

	# Everything else: the Nuxt SSR node service
	handle {
		reverse_proxy nuxt:3000
	}
}
```
