# Feature: Homepage combinada (gaming-bold)

## O que foi implementado

`/` deixou de ser só o grid cru e virou uma **home combinada**: hero + "como funciona o
escrow" + faixa de confiança/números + a vitrine de anúncios, tudo numa página fina que
só monta componentes. Visual "gaming-bold" (hero dark com gradiente) dentro do PrimeVue/Aura.

Seções: `HomeHero` (headline + CTAs Ver vitrine / Anunciar) → `HomeHowItWorks` (3 passos:
retém → entrega/recebe → libera −5%) → `HomeStats` (nº de anúncios ativos + selos de
confiança) → `ListingGrid` (vitrine + dialog de criar).

## Decisões técnicas

- **Home combinada** (não landing separada) — `/` continua sendo a entrada; sem rota nova.
- **Refactor**: o grid saiu de `index.vue` para o componente reutilizável `ListingGrid` (regra 11 — página fina).
- **`HomeStats` sem fetch extra**: lê o cache da vitrine via `useNuxtData('listings')` e usa o `total` do envelope paginado. Evita 2ª chamada a `/api/listings`.
- **Dialog de "Anunciar" compartilhado** entre `HomeHero` e `ListingGrid` via `useState('show_listing_form')`.
- **Gaming-bold dentro da regra 12**: gradiente do hero e glow de hover nos cards são CSS custom justificado (Aura não tem primitivo de hero); o accent usa `--p-primary-color` para acompanhar light/dark.
- **Sem backend novo** — "transações concluídas" ficaria pra um `/api/stats` (não feito); só mostro anúncios ativos + selos.

## Pitfalls / o que me surpreendeu

- Componente filho **não** deve usar top-level `await useAsyncData` (vira async component / Suspense). Usar sem await + `pending`. Páginas podem await (Nuxt embrulha em Suspense).
- `useNuxtData(key)` só lê o cache que **outro** `useAsyncData(key)` populou; o valor chega reativo depois que o grid carrega (mostro `—` até lá).
- Container `nuxt` é image-baked (igual ao `app`): pra ver no `http://localhost` precisa `docker compose up -d --build nuxt`.

## Redesign (mesmo dia — "estava muito simples")

Repaginada com a skill `impeccable` (register brand, comando `bolder`), corrigindo padrões "AI slop" que eu mesmo tinha shipado:

- **Removido gradient text** (`background-clip:text`) do hero — proibido; virou cor sólida + sublinhado `box-shadow inset` ouro.
- **HomeHowItWorks**: de 3 cards idênticos → **fluxo numerado** (numerais com `-webkit-text-stroke`, trilho conector). De-card.
- **HomeStats**: de template hero-metric (número grande + label) → **banda escura de confiança** ("Compre sem medo de calote") + chips de jogos (mostra alcance "qualquer jogo").
- **HomeHero**: full-bleed, assimétrico (1.15/0.85), type display em escala grande, **showcase de cards de produto** flutuando, reveal escalonado (`ease-out-expo`, respeita `prefers-reduced-motion`), paleta comprometida verde-ink + verde + ouro, grão SVG sutil.
- **Tipografia**: adicionada **Bricolage Grotesque** (display, Google Fonts via `nuxt.config app.head`) em `h1/h2/h3`; tokens `--ink`/`--gold` em `app/assets/css/main.css`. Layout ganhou `overflow-x:clip` p/ o full-bleed.

Tudo dentro da regra 12 (CSS custom justificado por comentário; PrimeVue nos botões/cards reais).
