# Sprints — quando criar uma nota

Pasta destinada a **retrospectivas de sprint**. Hoje vazia porque o time ainda não adotou cadência fixa de retros.

## Quando criar uma nota aqui

- Ao **encerrar uma sprint** (formato Scrum) — usar [[Templates/Sprint]]
- Para **registrar marcos** maiores do projeto (ex: lançamento de feature crítica que envolveu múltiplas sub-features)
- Como **periódico mensal** se sprints formais não forem usadas — registrar contexto agregado do que foi feito + dívida gerada

## Convenção de nome

`Sprint-XX YYYY-MM-DD.md` ou `YYYY-MM marco-do-mes.md`

## Por que importa

Sprint notes ligam features, bugs e dívidas em uma narrativa temporal. Sem elas, o vault fica com fatos isolados sem contexto de "por que isso aconteceu nessa janela". Mesmo uma nota mensal curta agrega valor.
